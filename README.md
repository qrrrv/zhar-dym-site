# Жар & Дым

Одностраничный сайт городской шашлычной в стиле Material Design 3 / Material Hearth.

## Запуск

```bash
npm run dev
```

Откройте `http://localhost:3000`.

## Проверки

```bash
npm run check
npm run build
```

Сайт статический: контент и SEO-разметка находятся в `index.html`, интерактивы меню и корзины — в `script.js`, визуальная система — в `styles.css`.
